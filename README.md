# Online supplementary materials of Mulder, Voelkle, and Hamaker (under review)

These online supplementary materials provide the R code that was used for the simulation study in the manuscript ``Time Aggregation and Missing Time Frames in Causal Research With Panel Data''. The website containing the materials can be found at [https://jeroendmulder.github.io/time-aggregation](https://jeroendmulder.github.io/time-aggregation).
