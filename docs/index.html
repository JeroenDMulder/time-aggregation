Simulation Study

For the simulation study, data were generated in R and C++ using the R packages Rcpp (Eddelbuettel and François 2011) and RcppArmadillo (Eddelbuettel and Sanderson 2014). Analyses of the generated data were performed using Mplus version 8.11 (Muthén and Muthén 2017) for Scenarios 1 and 2 and using the R package lavaan (Rosseel 2012) for Scenario 3.
